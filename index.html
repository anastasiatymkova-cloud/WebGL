About the Model

This application renders a pear-shaped mathematical surface using indexed triangles and WebGL Vertex Buffer Objects (VBOs). The surface is generated parametrically using U and V coordinates. Vertex normals are calculated analytically from the cross product of the partial derivatives. Gouraud shading is implemented in the vertex shader using ambient, diffuse and specular lighting components. A single point light source moves continuously around the surface. Two interactive sliders allow users to adjust the surface granularity along the U and V directions in real time.
